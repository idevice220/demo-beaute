# Site de démonstration — NEX-WEB

Site vitrine fictif réalisé par [NEX-WEB](https://nex-web.fr) pour illustrer ce qu'un commerce local peut obtenir : design sur-mesure, fonctionnalités utiles (réservation, estimation, avis, galerie…), rapidité et mobile d'abord.

Toutes les données (entreprise, prix, avis, personnes) sont inventées. Le site n'est pas indexé par les moteurs de recherche.

## Développement

```bash
npm install
npm run dev
```

Next.js 14 · Tailwind CSS 3 · aucune base de données : les formulaires simulent l'envoi.
